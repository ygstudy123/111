         VisionGuard 后端服务 - 启动说明
═══════════════════════════════════════════════════════════════

【问题】
网站前端提示 "Failed to fetch" 或无法连接服务器。

【原因】
海康互联开放平台的 API 需要 RSA 私钥签名认证，私钥（AppSecret）
绝对不能暴露在前端代码中。因此需要一个后端服务来处理签名和 API 调用。

【解决步骤】

1. 安装 Node.js（>= 16）
   https://nodejs.org 下载安装

2. 进入后端目录
   cd server/

3. 安装依赖
   npm install

4. 启动服务
   npm start

   服务将启动在 http://localhost:3001

5. 使用网站
   - 保持后端服务运行
   - 打开前端网站
   - 填入 AppKey 和 AppSecret
   - 点击测试连接
